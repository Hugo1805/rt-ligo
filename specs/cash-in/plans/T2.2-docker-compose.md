## Objetivo
PostgreSQL y Redis locales con healthchecks, y archivos de entorno para dev y test.

## Contexto
El perfil `e2e` con `app1`, `app2`, `nginx` y `mock-psp` se agrega en T7.2. Aquí solo van las dependencias de infraestructura.

Bun carga `.env` en desarrollo y `.env.test` cuando corre `bun test`, porque `bun test` define `NODE_ENV=test`.

## Archivos
| Acción | Ruta | Contenido |
|---|---|---|
| crear | `docker-compose.yml` | Servicios `postgres` y `redis`. |
| crear | `.env.example` | Todas las variables de design §13 con valores locales. |
| crear | `.env.test.example` | Igual, apuntando a la base `cashin_test`. |

## Pasos
1. Servicio `postgres` con imagen `postgres:16-alpine`, usuario y clave `cashin`, base `cashin`, puerto `5432`, volumen nombrado y healthcheck con `pg_isready`.
2. Servicio `redis` con imagen `redis:7-alpine`, puerto `6379` y healthcheck con `redis-cli ping`.
3. `.env.example` con `DATABASE_URL=postgresql://cashin:cashin@localhost:5432/cashin`, `REDIS_URL=redis://localhost:6379`, `WEBHOOK_SECRET=dev-secret-change-me`, `PROVIDER_MODE=fake` y el resto de design §13 con sus defaults.
4. `.env.test.example` igual pero con la base `cashin_test` y Redis en la base lógica `1`: `redis://localhost:6379/1`.

## Restricciones
- No agregar el servicio de la app todavía.
- No commitear `.env` ni `.env.test`. Solo los `.example`.
- La base `cashin_test` la crea Prisma Migrate en T2.3. No usar scripts SQL de init.

## Trampas conocidas
- El agente tiende a usar `version: "3.8"`, que ya está obsoleto en Compose. No incluir `version`.
- El agente tiende a usar `depends_on` sin `condition: service_healthy`. Aplica recién en T7.2, pero los healthchecks deben existir ya.

## Criterios de aceptación
- [ ] `docker compose up -d postgres redis` levanta ambos servicios.
- [ ] `docker compose ps` muestra ambos como `healthy`.
- [ ] Las variables de los `.example` cubren toda la tabla de design §13.

## Verificación
    docker compose up -d postgres redis
    docker compose ps
    docker compose exec redis redis-cli ping
