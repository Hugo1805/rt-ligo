## Objetivo
Proyecto Bun con TypeScript estricto, dependencias del stack y scripts para dev, typecheck y los tres niveles de test.

## Contexto
El repo hoy solo tiene specs y docs. No hay `package.json`.

## Pasos
1. `bun init` sin plantilla de ejemplo, o crear `package.json` a mano con `"type": "module"` y `"private": true`.
2. Instalar dependencias de runtime: `hono`, `@hono/zod-validator`, `zod`, `@prisma/client`, `ioredis`, `pino`.
3. Instalar dependencias de desarrollo: `prisma`, `typescript`, `@types/bun`.
4. Si la versión estable de Prisma lo exige, instalar también su driver adapter de PostgreSQL. Seguir la guía oficial de la versión instalada.
5. Definir scripts:

| Script | Comando |
|---|---|
| `dev` | `bun --watch src/server.ts` |
| `start` | `bun src/server.ts` |
| `typecheck` | `tsc --noEmit` |
| `test:unit` | `bun test .unit.test` |
| `test:int` | `bun test .int.test` |
| `test:e2e` | `bun test .e2e.test` |
| `db:generate` | `prisma generate` |
| `db:migrate` | `prisma migrate dev` |
| `db:deploy` | `prisma migrate deploy` |
| `db:seed` | `bun prisma/seed.ts` |

6. `tsconfig.json` con `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `noImplicitOverride`, `moduleResolution: "bundler"`, `module: "ESNext"`, `target: "ESNext"`, `types: ["bun"]`, `noEmit`.
7. Crear la estructura de carpetas vacía.
8. Crear `src/smoke.unit.test.ts` con un `expect(1 + 1).toBe(2)` importado desde `bun:test`.

## Restricciones
- Usar las últimas versiones estables. No fijar versiones viejas por costumbre.
- `zod` en su versión mayor actual. Los schemas de los specs usan la API de zod 4.
- Nada de Jest, ts-jest, vitest, eslint ni prettier en esta tarea.

## Trampas conocidas
- El agente tiende a agregar `jest` o `@types/jest`. Prohibido.
- El agente tiende a crear carpetas por capa como `controllers/` o `services/`. La estructura es Feature-First.
- `bun test .unit.test` filtra por nombre de archivo. Verificar que efectivamente encuentra solo los `*.unit.test.ts`.

## Criterios de aceptación
- [ ] `bun install` termina sin errores.
- [ ] `bun run typecheck` termina sin errores.
- [ ] `bun run test:unit` corre y pasa el smoke test.
- [ ] `bun run test:int` no encuentra el smoke test.
- [ ] No hay dependencias fuera del stack de AGENTS.md.
